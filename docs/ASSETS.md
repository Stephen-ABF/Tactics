# Asset provenance

- All current meshes, UI shapes, scenery, effects and procedural animations: original project geometry/code, MIT license in the repository.
- Four static sample GLBs in `assets/models/`: generated from the project's earlier procedural actor meshes. They are reference assets; runtime actors are constructed by `scripts/actor.gd` unless art overrides exist.
- Sounds: locally synthesized tones from `scripts/audio.gd`; no sampled recordings or external music.
- Font: Godot's built-in fallback font. Engine/font third-party notices must accompany redistributed engine builds; see the official Godot license and copyright notices supplied with the engine.
- No purchased, scraped, AI-generated bitmap or third-party franchise art is included in this revision.
- New artist assets should record creator, source, license and any required attribution here before release.
