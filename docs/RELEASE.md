# Release preparation

Completed in source: full five-wave loop, tutorial, run progression, gear persistence, resumed runs, settings, restart/retry, offline logs, Android/Windows export presets and automated checks. Art is intentionally provisional.

Before public testing: download a successful CI debug artifact or export locally, install on actual Android hardware, verify touch at6×6, notch/navigation safe areas, background/resume, force-close restore, audio, low graphics, heat/battery and performance. Test at least one modest device. Software-rendered desktop screenshots are not hardware performance measurements.

Before store submission: choose final package ID; create/use the developer account; secure a private release upload keystore with backups; configure release signing; export and validate an Android App Bundle; satisfy the then-current store target API/testing requirements; prepare final icon/screenshots/listing/age rating/data-safety and privacy disclosures; supply engine/asset notices; run platform pre-launch tests; submit for review. None of those account/signing/review steps has been performed. CI creates a disposable debug keystore only.

No advertisements, purchases, accounts, multiplayer, backend or remote analytics. Store policy and signing requirements must be verified when submitting. Do not label this build published or device-tested until those actions occur.
